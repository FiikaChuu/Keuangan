# Noto Sans fonts

Unmodified Latin WOFF2 files for weights 400, 500, and 600, copied from @fontsource/noto-sans 5.3.0. Licensed under the SIL Open Font License 1.1; see [OFL.txt](OFL.txt).

These files are tracked with the application so both Vite development and production builds work without installing a separate font package.
